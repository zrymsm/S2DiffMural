# S2DiffMural

Official implementation of **S²-DiffMural**, a diffusion-based framework for ancient mural restoration.

## Overview

S²-DiffMural aims to improve structural recovery and semantic preservation in mural image restoration.

## Contents

- Complete source code
- Training and testing scripts
- Blob-mask and stroke-mask experiments
- Ablation study implementations
- Pretrained model weights
- Evaluation scripts
